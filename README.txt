NUVEM FOFA DESKTOP - BASE DE MIGRACAO

Este pacote transforma a interface V9 em um aplicativo desktop Electron.
O backend continua sendo o mesmo Firebase, portanto contas, servidores e mensagens continuam compartilhados.

TESTE RAPIDO:
1. Instale Node.js LTS uma vez, se ainda nao tiver.
2. Execute INSTALAR-E-ABRIR.bat.

GERAR INSTALADOR .EXE:
Execute GERAR-INSTALADOR-WINDOWS.bat.
O instalador sera criado em dist/.

OBSERVACAO:
Esta e a fundacao da versao desktop. A proxima fase deve substituir os filtros de ruido do navegador por processamento dedicado (RNNoise/WebRTC APM) e consolidar a captura de audio do sistema.
